1. System Overview

Questa is a comprehensive online HND question bank system designed for CITEC-HITM. It provides students with centralized access to past examination papers, interactive quizzes, exam results, timetables, academic calendars, news updates, library resources, financial status tracking, and an AI-powered chatbot assistant.

The system was developed following the Agile methodology using PHP, MySQL, HTML, CSS, and JavaScript. It features role-based access control, a centralized PDF repository, real-time notifications, and a fully responsive design that works on desktop, tablet, and mobile devices.

2. Key Features

🔐 Authentication & Security

  • Secure login with password hashing (bcrypt)

8. How to Run This Project Locally on PC

Prerequisites

  • XAMPP (Apache, MySQL, PHP) - Download from https://www.apachefriends.org
  • Git (optional) - Download from https://git-scm.com
  • VS Code (recommended) - Download from https://code.visualstudio.com
  • Web Browser (Chrome, Firefox, or Edge)

Step 1: Install XAMPP

1. Download XAMPP from https://www.apachefriends.org 2. Run the installer (accept all default settings) 3. Open XAMPP Control Panel 4. Click "Start" for Apache 5. Click "Start" for MySQL 6. Verify both are running (green highlights)

Step 2: Download the Project

# Option A: Clone with Git cd C:\xampp\htdocs git clone https://github.com/ndisilas/questa-hnd-question-bank.git questa_final # Option B: Download ZIP from GitHub # 1. Go to https://github.com/ndisilas/questa-hnd-question-bank # 2. Click Code → Download ZIP # 3. Extract to C:\xampp\htdocs\QUESTA_FINAL

Step 3: Create Database

1. Open your browser and go to: http://localhost/phpmyadmin 2. Click "New" on the left sidebar 3. Enter database name: questa_db 4. Click "Create"

Step 4: Import Database

1. Click on "questa_db" on the left sidebar 2. Click "Import" tab 3. Click "Choose File" 4. Select the SQL file from QUESTA_FINAL/questa_db.sql 5. Click "Go"

Step 5: Configure Database Connection

Open includes/config.php and verify these settings: $host = 'localhost'; $dbname = 'questa_db'; $username = 'root'; $password = '';

Step 6: Create Upload Directories

Make sure these folders exist and are writable: uploads/ uploads/avatars/ uploads/papers/

Step 7: Access the System

Open your browser and go to: http://localhost/questa_final/login.php Use the login credentials from Section 4 above.
